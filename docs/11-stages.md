# §11 — Developmental Stages

(SI's framing — newborn language lives only in this file.)

Stage is **derived from state each THINK tick**, never a hardcoded counter.
A baby regresses if its supporting rows get superseded away. Entry/exit
criteria are counts over learned rows — SI only advances through
conversation.

| stage | name | entry | exists at this stage | exit | owner's job (only way forward) |
|-------|------|-------|----------------------|------|-------------------------------|
| S0 | **BIRTH** | fresh CONFIG SI session | S-R pair storage; named-slot ask-back + fallback nonce (R11/R16); exact-pattern recall; **all three teaching channels live (§1.4)** — `/correct`, answer-to-ask auto-commit, and `/teach` (a `/teach` counts as an S-R row like any other; the stage law is counts over rows and never asks which channel filled one — and the published limit: **`/teach` alone cannot exit S0**, because the exit needs a *supersession*, which is an edit, and a curriculum only ever adds) | ≥ 5 S-R rows with ≥ 1 supersession | type questions, **answer the questions it asks you plainly** (`red.` is enough), `/correct` when you want to override, `/teach` what you want known in one act, change your mind |

## 11.1 Affect does not gate stages — but it must show a trajectory (§18.4)

Stages stay **count-based over learned rows** (nothing in §18 or §19 changes
entry/exit criteria — an emotion label can never promote a stage, that would be
a hidden prior; and since round 2 they could not even if someone wanted it,
because **labels have no causal path at all**, §18.2). What the affect batch
adds to this section is three visible facts:

- **Every stage has the same physics, and the physics never matures.** CONFIG
  SI is born with one integrator at rest and the modulation curve (§18.1) —
  identical to the adult's. Round 1's OPEN-20 / OD-17 ("does a newborn feel
  CAUTION, does hysteresis arrive later like depth perception?") is
  **cancelled**: there is no coupling matrix to mature. What develops is the
  *content* the signals point at — the rows, edges and stamps the arousal curve
  is measured over. The surviving developmental question is about the **audit
  classifier**, not about the machinery (OPEN-22: does the label vocabulary get
  richer as more co-occurrence data accumulates?).
- **Session logs must read as one curve plus a label stream:** `a` rising on
  cited signals and decaying on `λ_a`, **within** a thought as well as across
  them (§20.1 — the curve is now a trajectory, and the log shows which round ran
  at which `a`), with the audit's words (*curiosity,
  surprise, satisfaction, caution, frustration*) printed beside it — continuous,
  never flag-shaped (§18.4). A curve that jumps with no signal row behind it, or
  a label that changes behavior, is the costume test failing (§18.7).
- **Round 3 adds a stage-adjacent observation it must not turn into a gate
  (§20.3):** early sessions have few stamps, so most point medians are
  **undefined** and emotional readings barely exist yet — the system is
  legitimately *plastic* at S1 and progressively *harder to move* later, because
  a median needs repetition to shift. That is development in the affect channel
  without any maturation of the machinery, and **no stage entry or exit may be
  defined on it** (§11's law stands: the physics never matures — only its
  measured inputs accumulate).
- **The developmental marker affect gives us for free:** across sessions the
  *same* content produces a smaller arousal rise (novelty falls, coverage rises,
  §6.2), so the curve flattens on well-taught slots while fresh ones still spike
  — a stage-ish observation without being a stage gate, and the one honest
  reading of "getting calibrated with age" available in v1. The idle tail adds
  the second marker: as the connectome grows, ignition has more candidates with
  decay deficits, so **the monologue gets longer with learning** (§19) without
  anybody scheduling it.

## 11.2 The supporter does not move the ladder ([docs/21](21-grimm-supporter.md))

Nothing in §11's entry/exit criteria changed when Grimm arrived, and that is a
law, not an accident: **stages are counts over learned rows, and Grimm cannot
create a learned row** (§21.4). Three statements, so nobody has to re-derive
them during the build:

- **A stage never advances because Grimm is ready.** The direction of that
  dependency is the whole design: **he** unlocks against **SI's** state (v2 at
  G2's decode leg, v3 at G4 — §21.6), never the reverse. If a ladder criterion
  ever reads a Grimm-side flag, the owner has been replaced by a tutor and §1's
  "the owner controls developmental pace by typing alone" is dead.
- **He can change the *pace* the honest way.** More echoes of a taught token
  means more lighting of the same edges, which is rehearsal (§8.4's decay curve),
  which is exactly what a parent in the room does. Pace comes from **more
  exposure to what the owner already taught**, not from new content — the second
  channel stays owner-only.
- **`repeats` and confidence are not his to move** (§6.2, R-35): the S0→S1
  criterion is "≥ 5 S-R rows with ≥ 1 supersession" — all row-shaped, all
  owner-shaped. A run where Grimm's mirroring accelerates a stage transition is
  a run where a belief got a counterfeit confirmation, and G12(d) is written to
  catch precisely that.

## 11.3 The v2 arc moves no rung either ([docs/22](22-crystallize.md)–[docs/26](26-world.md))

Same law, five new mechanisms, and the same reason: **the ladder is counts over
learned rows**, and the arc deliberately adds no new way for a row to become
learned without the owner.

- **Crystallize and skills cannot mint a rung.** A nomination is an ask; only an
  owner-confirmed reply runs the ordinary write gates, and the row it writes is
  an ordinary L3 row with ordinary provenance. So the arc changes *what SI can
  propose*, never *who can teach* (§1's "the owner controls developmental pace
  by typing alone" is untouched — the confirmation is typing).
- **The one seam the fold found, and did not paper over.** S2's criteria count
  `links` rows kind-blind, and a confirmed cluster point lands on `links`. So
  tonight **it counts**, because the build added no discriminator — which is the
  least-authority option, not a ruling. Whether a nominated cluster *should* be
  allowed to satisfy a criterion written for `P_DEF` teaching is **OD-133**
  ([docs/22 §22.9](22-crystallize.md)); a build that quietly excluded the kind
  would be editing the ladder while claiming not to touch it.
- **No other voice moves the ladder either — and that is §11.2 generalized.**
  Under tier (a) a stranger's line writes `context` rows only, so it cannot
  satisfy an S-R, fact or `links` count at all; under a grant it writes exactly
  what an owner line writes, through the same gates, and advances a stage for the
  same reason the owner does (**G19(a)** is therefore also a stage-leg: ten
  strangers talking with the owner silent advances no rung, because their lines
  are `context` rows and every rung's criterion counts S-R, fact or `links`
  rows). Delegated authority is a *teaching* delegation, not a *ladder*
  delegation — the rungs stay SI's own.
- **Silt, the event view and the frame scratch are read-side**, so they can
  change what a tick *thinks about* (pace, honestly, as §11.2 allows Grimm) and
  cannot change a count. The arc's fifth ignition weight rides the same
  asymmetry: warmth picks the seed, the seed forms nothing.
- **Affect still shows a trajectory and still gates nothing** — the arc inherits
  §11.1 wholesale: the crystallize detector **never reads `a`** (§22.3's hard
  exclusion), and no stage criterion reads `a`, a median, a bake, or an audit
  label (I8, **G15(c)**, **G16(c)**, **G17(c)**). What arousal does change is
  which frames the walk settles — the walk's own lawful job (§20.1) — so mood
  reaches a nomination only the way it reaches every other thought: by having
  altered which edges were cheap, visibly, in the trace.

## 11.4 The tongue moves no rung either ([docs/27](27-tongue.md))

Same law, third time, for the same reason: **the ladder counts rows, and the
tongue writes no row.** Surface realization happens after the label, on the way
out the door, and its entire write set is empty — no belief, no edge, no stamp,
no byte. Four statements for the build to check against rather than re-derive:

- **With `TONGUE` off, no criterion can see the phrase at all.** The switch is a
  Ruling row, and the V0 output is `render.py`'s canonical copy byte for byte
  (**G20(j)**). So the stage ladder is literally the same code path at V0 that
  §11–§11.3 were written against.
- **A voice cannot buy pace.** The five style draws are TEMPERAMENT-class rows,
  and no sweep touches a TEMPERAMENT row (OD-87, OD-177); a run whose phrasing
  happens to please cannot advance a rung, because there is nothing it does to a
  rung's countable input.
- **A realized line is never fed back** (§27.5, **G20(f)**). The accent changes
  which surfaces are cheap to pick; the accent is not itself a surface that gets
  taught, so SI cannot advance a stage by repeating its own speech. This is the
  self-reinforcement shape R-43 names, and it is closed at the read side.
- **Fluency is not comprehension, and the ladder never reads fluency.** The
  tongue's three structural checks gate *form*; every rung's criterion counts
  *content* rows with provenance. A run that sounds fluent and has learned
  nothing sits at exactly the stage it sat at before the switch existed — which
  is the §27 two-litmus reading of "the voice may vary, the ladder may not."
